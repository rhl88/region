# CmsPro-中国行政区划-使用指南

> 版本：1.5.0 | 更新日期：2026-09-13
> 应用版本：1.0.1 | 应用 ID：cmspro.region

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 系统 | CmsPro v5.0.0+ |
| PHP | >= 8.3 |
| 数据库 | MySQL |
| 网络 | 导入数据需访问民政部 API（`https://dmfw.mca.gov.cn`） |
| 依赖应用 | 无 |

---

## 二、安装

1. 通过 CmsPro 后台「应用市场」安装中国行政区划应用，或手动将应用包上传安装。
2. 安装过程中自动创建数据库表（`app_cmspro_region_region` 和 `app_cmspro_region_closure`）。
3. **注意：安装后数据表为空，需进入后台「行政区划 → 数据管理」页面手动导入数据。**

> 卸载应用会回滚业务数据表。

## 三、功能验证

### 3.1 后台验证

后台入口前缀 `/admin/cmspro/region`（中间件 `web + auth:admin`）：

| 菜单 | 路径 | 验证点 |
|------|------|--------|
| 数据管理 | `/admin/cmspro/region` | 数据导入/更新、街道分步导入、缓存清除、数据对比更新、地理位置导入 |
| 数据演示 | `/admin/cmspro/region/demo` | 区划选择器演示、地址位置信息展示、数据状态检查与导入引导 |

### 3.2 导入三级数据

安装完成后，在后台「行政区划 → 数据管理」页面中，推荐点击「**一键导入**」按钮（使用本地数据包自动完成三级区划、街道数据、地理位置全量导入，无需联网）；也可点击「导入三级数据」单项按钮（或「一键导入」悬停菜单中的「导入三级数据」项）仅导入省/市/区县数据。由于三级数据有 3200+ 条（含港澳台），系统采用**按省份分步导入**策略：

1. 前端获取省份列表（34 个）。
2. 逐个省份通过 AJAX 请求导入，每次请求处理一个省份。
3. 进度条实时显示导入进度，日志记录每个省份的导入结果。
4. 每个省份独立请求，即使服务器配置较低也不会超时。

### 3.3 启用街道级数据（可选）

如需使用街道/乡镇四级数据，在 CmsPro 后台「系统设置 → 区划设置」中开启「启用街道级数据」选项。开启后在后台页面点击「导入街道数据」按钮，系统按省份/区县分步导入（约 4 万+ 条），支持本地缓存文件 `Data/code/{区县代码}.json`。

### 3.4 导入地理位置数据（可选）

如需使用城市和区县的经纬度信息，在后台页面点击「导入地理位置」按钮。数据来源为本地 Excel 文件 `Data/地理位置编码.xlsx`，按省份分步导入。

### 3.5 在线更新坐标（GeoJSON，可选）

本地 Excel 数据源较旧（如 2023-24 新设区伊美区、湾沚区等无坐标），可在后台页面点击「在线更新坐标(GeoJSON)」按钮，从**阿里 DataV 地理数据源**（`geo.datav.aliyun.com`，免费、免 key）按省份在线拉取最新坐标并更新库中记录：

1. 前端获取库中省级列表，逐省请求导入接口。
2. 每省先更新省级自身坐标，再遍历下级市级/区县级坐标（直辖市区县、港澳区级直接取自省级文件）。
3. **名称兜底匹配**：DataV 部分编码沿用旧版（如繁昌区 DataV 340211 vs 库中 340212），编码未命中时自动在同省范围内按名称匹配，避免编码差异导致漏更新。
4. 每省返回更新/坐标相同跳过/未匹配/异常四项统计，前端逐省展示日志。

> 覆盖说明：实测省级+市级+区县级覆盖率约 3166/3213；剩余为 2023-24 最新设市县（米林市、错那市、和康县、和安县、新星市、白杨市、草湖市 7 条）DataV 暂未收录，无法通过该方式获取。坐标为 GCJ-02 坐标系，与高德地图瓦片一致。

### 3.6 数据演示

后台「行政区划 → 数据演示」页面提供区划选择器和地址位置信息的可视化演示：

1. **数据状态总览**：页面顶部展示三级区划数据、街道数据、地理位置数据的导入状态。
2. **导入引导**：未导入对应数据时，页面显示引导提示和跳转按钮，引导用户前往数据管理页面导入。
3. **区划选择器**：三级数据已导入时，提供省/市/区县（+街道）级联选择器，选择后显示完整路径。
4. **地址位置信息**：地理位置数据已导入时，选中区划后展示区划代码、名称、完整路径、经纬度信息。
5. **地图定位演示**：选中区划含经纬度坐标时，在 Leaflet + 高德瓦片地图上自动定位该区划位置并标记弹窗；任一级选中即触发（直辖市在省级选区县时同样生效）。地图组件依赖 CDN，加载失败时显示降级提示，不影响页面其他功能。

> 三级区划数据是演示的基础，未导入时选择器不显示；街道数据和地理位置数据为可选项，未导入时对应功能不展示，并提示导入引导。

### 3.7 一键导入 / 一键数据更新（推荐）

后台「行政区划 → 数据管理」页面顶部提供两个主按钮——「**一键导入**」（蓝色，使用应用内置本地数据包从零导入全量数据，**无需联网**）与「**一键数据更新**」（绿色，从在线源增量更新旧数据）。两者链路相互独立，单击即可自动执行；**两个按钮均支持鼠标悬停下拉菜单**：「一键导入」菜单收纳本地链路三个单项入口（导入三级数据 / 导入街道数据 / 导入地理位置，标题为「本地数据导入」，悬停高亮蓝色），「一键数据更新」菜单收纳五个单项入口（导入三级数据 / 导入街道数据 / 导入地理位置 / 更新坐标 / 补全港澳台），点击菜单项即触发对应单项功能。

**一键导入（本地数据，3 阶段）**：

| 阶段 | 内容 | 数据源 | 说明 |
|------|------|--------|------|
| ① 三级区划 | 省/市/区县导入 | 本地 `Data/list.json` | 逐省分步写入，单请求秒级完成 |
| ② 街道数据 | 约 4 万+ 条街道/乡镇 | 本地 `Data/code/*.json`（无缓存则调民政部 API） | 逐区县串行导入，失败区县自动追加一轮重试，耗时最长 |
| ③ 地理位置 | 城市/区县经纬度 | 本地 `Data/地理位置编码.xlsx` | Excel 全量导入（单请求） |

**一键数据更新（在线源，4 阶段）**：

| 阶段 | 内容 | 数据源 | 说明 |
|------|------|--------|------|
| ① 三级区划 | 省/市/区县差异化更新 | 民政部 API | 逐省分步请求，单请求秒级完成，不会超时 |
| ② 港澳台补全 | 修正台湾省级脏编码、补全港澳区级 | 阿里 DataV | 失败不中止整体流程（非关键路径） |
| ③ 街道数据 | 约 4 万+ 条街道/乡镇 | 民政部 API（本地缓存优先） | 逐区县串行导入，失败区县自动追加一轮重试，耗时最长 |
| ④ 最新坐标 | 省/市/区县经纬度更新 | 阿里 DataV GeoJSON | 逐省串行更新 |

交互说明：

1. 点击按钮弹出确认框（确认文案按「一键导入（本地数据）/ 一键数据更新（全在线源）」区分），展示各自阶段流程与耗时提示；确认后自动按顺序执行。
2. 统一进度面板显示当前阶段（步骤标签高亮，本地导入模式隐藏「最新坐标」标签）、整体进度条与实时日志；进度条按阶段分段映射（0~5% / 5~30% / 30~85% / 85~99%）；执行中标题与日志按入口按钮与链路模式区分显示。
3. 两个主按钮的悬停下拉菜单提供单项导入入口（导入菜单 3 项、更新菜单 5 项），与一键导入/一键更新共用同一套互斥机制：任一任务（含一键导入、一键更新或单项导入）执行期间，两个主按钮与菜单项同步禁用，防止并发冲突；执行中不可关闭进度面板。
4. 「一键导入」全程使用本地数据包无需联网；「一键数据更新」需联网；街道阶段数据量大（约 1 小时），执行期间请勿关闭或刷新页面。

> 适用场景：新装应用（或离线环境）点击「一键导入」，基于应用内置 `Data/` 目录官方数据包从零拉起全量数据；已安装应用且数据为旧版本时，点击「一键数据更新」从在线源增量更新。

### 3.8 API 验证

统一响应格式：`{"code": 0, "message": "success", "data": ...}`，`code = 0` 成功。

```bash
# 获取所有省份列表
curl "http://www.cmspro.com/api/admin/cmspro/region/provinces"

# 获取子级区划列表
curl "http://www.cmspro.com/api/admin/cmspro/region/children?code=110000"

# 获取完整树形数据
curl "http://www.cmspro.com/api/admin/cmspro/region/tree?max_level=3"

# 获取完整路径
curl "http://www.cmspro.com/api/admin/cmspro/region/path?code=110101"

# 获取数据统计
curl "http://www.cmspro.com/api/admin/cmspro/region/stats"
```

## 六、常见问题

### Q: 安装后没有数据？

安装应用仅创建数据库表，需在后台「行政区划 → 数据管理」页面手动点击「导入三级数据」导入。

### Q: 导入数据提示超时？

三级数据采用按省份分步导入策略，每个省份独立请求，不会超时。如仍异常，请检查服务器能否访问民政部 API。

### Q: 如何启用街道/乡镇四级数据？

在 CmsPro 后台「系统设置 → 区划设置」中开启「启用街道级数据」选项，然后在数据管理页面点击「导入街道数据」。

### Q: 数据更新后前台不生效？

查询结果缓存 24 小时，数据更新时自动清除；如仍异常，可手动点击「清除缓存」。

### Q: 直辖市如何查询子级？

北京、天津、上海、重庆的区县直接挂在省级下（无中间市级），`getChildren('110000')` 直接返回区县列表。
